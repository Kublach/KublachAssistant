# KublachAssistant

A cute little desktop companion for Windows. Every few minutes a character slides in from the corner of your screen with an animation, a message and a sound — reminding you to drink water, take a break, stretch, or just saying "I love you".

Features
Animated character pop-ups with a transparent background and a speech bubble
Scenes where image, text and sound go together (e.g. a character carrying water says "Drink some water!" with its own sound)
Multiple characters to choose from
Multiple languages for messages, depending on the character
Fixed or random interval: every X minutes, or a surprise moment between X and Y minutes
Adjustable display time for each pop-up
Sound on/off
System tray icon with a quick menu: show now, change character or language, random time, sound, pause, settings, exit
Runs quietly in the background: closing the window hides it to the tray
Remembers your settings between runs
Single .exe, no installation needed
Usage
Action	How
Show a character now	"Show now" button, or double-click the tray icon
Change character or language	Dropdowns in the window, or the tray menu
Random interval	Tick "randomly till" and set the upper limit
Pause / resume	"Pause" / "Start", or the tray menu
Hide the window	Close it with X; the app keeps running in the tray
Quit	"Exit" button, or tray menu → Exit

Click on a pop-up to dismiss it early.

Start with Windows

Press Win + R, type shell:startup and put a shortcut to Bubu Assistant.exe in the folder that opens.
